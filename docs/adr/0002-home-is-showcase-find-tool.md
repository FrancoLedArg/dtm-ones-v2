# Home is the Showcase find tool

Landing is a public **roster tool** for ~200 Players and Coaches, not a small marketing poster feed. **Home is the Showcase**: name search, one Dashboard-owned **Category** filter, **compact cards**, and a thin **License** strip. **Signing posters** (Instagram `@dtm.ones` system) belong on detail pages. We rejected keeping issue #4’s marketing-scroll Home and a dedicated `/players` index as the primary find surface, because find-efficiency is the job and Evaluators arrive ~50/50 via deep link vs self-serve roster find (owner need pattern: “I need a pivot”).

## Consequences

- Issue #4’s Home IA (Hero → Showcase strip → Proof → Legends teaser → soft close) is superseded; see the reopened issue and [DESIGN-BRIEF.md](../../apps/landing/DESIGN-BRIEF.md).
- Category taxonomy is owned by the planned Dashboard/CMS; Landing only consumes labels (exactly one per entry).
- Parallax is deferred on the Home find grid; still preferred on detail/poster layers.
